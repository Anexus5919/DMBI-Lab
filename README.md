## Dataset

The data is synthetic and is generated by [`dataset/generate_dataset.py`](dataset/generate_dataset.py).
It follows the Experiment 1 schema: Rental_Fact with the Date, Car, Customer and Branch dimensions.

- 5,000 rentals from January 2024 to December 2025
- 12 branches in 10 cities, 22 car models (347 cars), 800 customers
- Measures: rental days, km driven, daily rate, rental amount, late fee, add-ons taken
- The raw file also has 45 duplicate bookings, missing values, mixed text and a few impossible
  values, so that the preprocessing in Experiment 2 has real work to do

How the experiments connect:

```
Exp 1 schema -> dataset -> Exp 2 clean data -> Exp 3 EDA
                                            -> Exp 4, 5 late return classification
                                            -> Exp 6 customer profiles -> Exp 7
                                            -> Exp 8 add-on transactions -> Exp 9
                                            -> Exp 10 warehouse and dashboard
```

## Running the code

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Each script runs from inside its own folder, for example:

```
cd Exp5_Classification_Python
python classification.py
```

Dashboard (Experiment 10): double-click `Exp10_BI_Dashboard/run_app.bat`, or

```
cd Exp10_BI_Dashboard
python build_warehouse.py
streamlit run app.py
```

RapidMiner experiments (4, 7, 9): open Altair AI Studio, use File > Import Process and pick the `.rmp`
file in the folder. If the repository is not at `C:\Users\ANEXUS\Desktop\DMBI-Lab`, update the file
path in the Read CSV operator.
